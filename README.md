# TaskFlow

TaskFlow adalah aplikasi web ringan untuk mengelola tugas harian. Aplikasi ini berjalan langsung di browser, menyimpan data di `localStorage`, dan tidak membutuhkan proses build.

## Fitur

- Tambah tugas dengan pilihan prioritas tinggi, sedang, atau rendah.
- Tandai tugas selesai dan lihat progres penyelesaian otomatis.
- Hapus tugas satu per satu atau bersihkan semua tugas yang sudah selesai.
- Tampilan responsif untuk desktop dan perangkat mobile.

## Menjalankan aplikasi

```bash
npm start
```

Buka `http://localhost:4173` di browser.

## Pengujian

```bash
npm test
npm run check
```
